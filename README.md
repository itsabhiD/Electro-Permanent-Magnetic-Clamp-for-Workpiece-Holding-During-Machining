# Electro-Permanent-Magnetic-Clamp-for-Workpiece-Holding-During-Machining
To replace power-hungry electromagnetic clamps, designed a 1500 lbf-rated clamp by moving from reluctance modeling to automated FEMM/MATLAB sweeps; selected N33/LNG40 magnets and verified in Ansys, achieving 1501 lbf ON/10.44 lbf OFF force, 45 °C peak, ~$18.70 cost.
